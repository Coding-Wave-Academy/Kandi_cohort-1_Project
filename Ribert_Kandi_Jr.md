## Project name: iLens

# Project Description
iLens is a mobile application that transforms screenshots from static images into actionable interfaces. After a one-time setup, iLens runs quietly in the background, automatically detecting screenshots, extracting meaningful elements, and presenting instant actions without requiring manual scanning.

Core principle: If you can screenshot it, you can act on it.

The experience begins as an app the user installs and configures once, then evolves into an invisible system layer that reduces friction across daily digital interactions.

# How It Works
Step 1
User takes a screenshot (any app, any content)
Step 2
iLens detects the screenshot via Media Store Observer
Step 3
On-device AI analyzes image — determines if actionable content exists
Step 4
If actionable: overlay appears with relevant action buttons
Step 5
If not actionable: iLens stays silent. No noise, no interruption.
